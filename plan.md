This is a hackathon project. We are inspired by the World Monitor. There is a link to the World Monitor dashboard. We are building specifically for the data centers and their effect on the surroundings. There is also a 7-point theme for what we are building: a project demo project. Before implementing this step by step, we want the UI of the World Monitor dashboard to be relevant to our project, with all the information.
What we are doing is only targeting 4 states:
- Maharashtra
- Karnataka
- Tamil Nadu
- Telangana
We have the data folder as well. We will mark all the data centers present in these 4 states. After clicking on a data center, all the data centers will be marked on the map, like World Monitor. After clicking on a data center, it will show all the information for that data center:
- capacity
- grade
- size
- water level
- cooling
- how it is affecting the area around it
- World AQI
- all the information required for the data center
We also have multiple features. We will predict from the model about the data center. We will come to the model training part later in this project.
We also have site evaluation, in which a government official can use our dashboard and select the site which is more useful. All the data centers will have a real-time risk score out of 100. The data and the news will be fetched in the dashboard only, or real-time news from the government or any important thing happening in these states.
This is basically for the government official and the ministry so that they can make their task around the data center easier, because a data center requires a lot of resources and we have to use them efficiently. We want to build this project, a demo one, but fully working from the frontend and backend.
- In the frontend, we will use TypeScript plus White.
- In the backend, Python in FastAPI and a SQL database for the data sources.
- All other APIs for every feature we require in one complete system
